# בינה טלפונית AI

לוח הגדרה בעברית למערכת מענה קולי עם AI, GitHub, Render וימות המשיח.

## פריסה ב-Render
- Runtime: Node
- Build command: `npm install --omit=dev`
- Start command: `npm start`
- יש להגדיר `BASE_URL` לכתובת HTTPS של השירות לאחר יצירתו.

לאחר שהלוח עולה, פותחים אותו בדפדפן ומזינים בעצמכם את הטוקנים של GitHub, Render, ימות המשיח וספק ה-AI. הלוח יוצר מאגר נפרד לבוט ושירות Render נפרד, ואז יכול להגדיר את השלוחה שבחרתם.

**חשוב:** בחרו שלוחה פנויה בלבד. הגדרת ימות משנה את ההגדרות של השלוחה שבחרתם. אל תשתפו מפתחות API בצ'אט או במאגר GitHub.
