# בינה טלפונית AI

לוח הגדרה בעברית למערכת מענה קולי עם AI, GitHub, Render וימות המשיח.

## אופן פעולת הדיבור
- ימות המשיח משמשת לקבלת ההקלטה בלבד — לא לזיהוי הדיבור.
- השרת מוריד את קובץ ההקלטה מימות המשיח באמצעות DownloadFile ושולח את האודיו ל-Gemini לצורך תמלול בעברית.
- התמלול נשלח למודל המענה שנבחר (Gemini, OpenAI או Claude), שמייצר תשובה שמושמעת למתקשר.
- אם ספק המענה אינו Gemini, יש להזין מפתח Gemini נפרד לתמלול. אם ספק המענה הוא Gemini, אותו מפתח משמש לשניהם.

## פריסה ב-Render
- Runtime: Node
- Build command: `npm install --omit=dev`
- Start command: `npm start`
- יש להגדיר `BASE_URL` לכתובת HTTPS של השירות לאחר יצירתו.

לאחר שהלוח עולה, פותחים אותו בדפדפן ומזינים בעצמכם את הטוקנים של GitHub, Render, ימות המשיח וספקי ה-AI. הלוח יוצר מאגר נפרד לבוט ושירות Render נפרד, ואז יכול להגדיר את השלוחה שבחרתם.

**חשוב:** בחרו שלוחה פנויה בלבד. הגדרת ימות משנה את ההגדרות של השלוחה שבחרתם. אל תשתפו מפתחות API בצ'אט או במאגר GitHub.
