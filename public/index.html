בינה טלפונית AI

מחברים ארבעה חשבונות, לוחצים פעם אחת, ומחייגים לדבר עם הבינה.

המפתחות משמשים לביצוע פעולות בשירותים השונים. אין להדביק אותם בצ'אט או במאגר ציבורי.

אם מסמנים, המפתחות נשמרים בדפדפן במכשיר הזה כדי שלא תצטרך להזין אותם שוב. אל תפעיל במכשיר משותף. השמירה אינה בכספת מוצפנת.

1

GitHub

איך מתחברים
התחברות עם GitHub

יפתח מסך אישור של GitHub. לוחצים Authorize ומוחזרים לכאן.

  1. התחברו ל-GitHub ולחצו על הכפתור למטה.
  2. צרו טוקן עם הרשאת repo.
  3. לחצו Generate token והעתיקו אותו מיד — הוא מוצג פעם אחת בלבד.
  4. הדביקו כאן ולחצו אימות טוקן.
יצירת טוקן GitHub
2

Render

איך משיגים מפתח
  1. היכנסו לחשבון Render.
  2. פתחו Account Settings → API Keys.
  3. לחצו Create API Key והעתיקו את המפתח שמוצג.
פתיחת Render
למאגר פרטי: ודאו ש-Render מחובר ל-GitHub ושהרשאות האפליקציה מאפשרות גישה למאגר החדש.
3

ימות המשיח

מפתח API ושלוחה פנויה
  1. היכנסו לניהול ימות המשיח ופתחו אבטחה → ניהול מפתחות גישה.
  2. צרו מפתח API, והדביקו אותו כאן.
  3. בחרו מספר שלוחה פנוי בלבד. ההגדרה תשנה את השלוחה שתבחרו לשלוחת API.
אתר הניהול של ימות המשיחניהול מפתחות גישה
אל תבחרו שלוחה פעילה או שלוחה שמכילה מערכת קיימת.
4

הבינה המלאכותית

בחירת ספק ומפתח API

אפשר להשתמש ב-Google Gemini בהתאם למגבלות המסלול החינמי, או בספק בתשלום.

  1. צרו מפתח API ב-OpenAI. נדרש Billing פעיל.
מפתחות OpenAI
  1. צרו מפתח API ב-Anthropic. נדרש קרדיט.
מפתחות Anthropic
  1. פתחו Google AI Studio ולחצו Create API key.
מפתחות Gemini

Gemini מחזיר תשובות כטקסט, וימות המשיח מקריאים אותן בקול המובנה שלהם. זיהוי ההקלטה נעשה באמצעות Gemini Flash Latest (gemini-flash-latest). אם בחרתם Gemini למענה, אותו מפתח משמש גם לתמלול; אם בחרתם OpenAI או Claude, הזינו כאן מפתח Gemini נפרד.

5

פתיח הקו

המשפט שיושמע בתחילת השיחה

הפתיח יוקרא על ידי ימות המשיח לפני שהמערכת תקליט את השאלה הראשונה.

המגבלה נאכפת גם בקוד השרת, כך שהבינה לא תוכל להאריך מעבר למספר שנבחר.

סימון האפשרות יחליף את ניתוב השלוחה הראשית לשרת הבוט, ועלול לעקוף תפריט או מערכת שכבר פועלים שם. השאירו לא מסומן כדי לשמור על השלוחה הראשית הקיימת.
